Released 2026-10-26. Container image:
`ghcr.io/gorkaabad/sbb@sha256:b887505c5eea2a63f69797da3a70c2769687d45ba7e7e0127f7524d39e73e1d9`
(`docker://` for Apptainer, see `docs/sites.md`).

How v0 and v1 came to their design. `docs/PLAN.md` says what holds now, and its section 13.3 lists
the tasks of this version.

## Changes during the build

- The triggered test set holds every test sample, and every metric but `asr_all` counts only the
  triggered samples whose true label is not the target. Before, the triggered test set left the
  target-class samples out.
- `Attack.trigger_test` became the attribute `trigger`, and `ScenarioInfo` gained `input_shape`.
- Dataset adapters decode the raw files themselves instead of wrapping SpikingJelly's classes.
- The benchmark moved to the papers' networks (user decision of 2026-10-16). `spiking_vgg11` and
  `sew_resnet18` left the plan of this version. `nmnist_net` came with the N-MNIST replications
  (user request of 2026-10-21).
- `lite_pp` went from 1.0 to 3.0, the replication tolerance (user decision of 2026-10-24). At 1.0,
  38 of the first 210 records mismatched: the lite results were produced on GH200 GPUs and rerun on
  GitHub CPUs, and defenses that make discrete choices (fine-pruning's neuron ranking, ANP's masks,
  TMPBD's p-value) flip on small float differences. The existing records were judged again at 3.0.

## Versions of `sneaky_dynamic`

- 1.0.1 trains with the official batch of 8. At 16, CIFAR10-DVS and DVS128 Gesture ran out of a 95
  GB GPU.
- 1.1.0 keeps an epoch when its clean and backdoor accuracy both beat those of the epoch kept so
  far, scored on 1000 samples of the attacker's own training split (the official code scores the
  test set, which an attacker never sees), then trains the official extra epoch with the learned
  trigger from that snapshot (user decision of 2026-10-23).
- 1.2.0 scores each epoch as the official test() does: a copy of the classifier first trains one
  epoch with the frozen generator, the copy is scored, and the best copy is returned (user decision
  of 2026-10-23). 1.1.0 scored the jointly trained model before that epoch, and its replication
  failed on DVS128 Gesture (CA 78.6 against 91) and CIFAR10-DVS (CA 14.8 against 44): when an early
  epoch already reaches 100% backdoor accuracy, the strict rule keeps it whatever its clean
  accuracy.

## Group B defenses (2026-10-22)

Ported, each a plugin and a card with no replication record: `spectral_signatures` and
`activation_clustering` (pre_training, on `reference_features`: a reference model trained on the
train set as received, represented by its readout inputs), `abl` (in_training, through
TrainerHooks), `nad` and `anp` (post_training). They stayed out of `benchmarks/v0.9.yaml` at first,
which kept the group A battery. NDSBM needed a core change: its clamps are extra modules, and the
Game stores a defended model as a state dict rebuilt from its ArchSpec, so a cached NDSBM model
would lose them. `ModelDefense.extra` and `attach` came from that.

Toy check on N-MNIST (`nmnist_tiny`, seed 0, GPU): every ported defense kept CA within 1 point of
the undefended 98.7 except ANP (94.1 to 97.7) and NDSBM. Against `static_patch` and `sneaky_static`,
STRIP rejected the triggered inputs (ASR 0.1 and 0.0) and the others left ASR between 98 and 100, as
T-Backdoor's Table I reports for ANP, CLP, fine-pruning, fine-tuning and NAD against the static
trigger on N-MNIST. NDSBM collapsed CA to 21 to 39%, also without an attack, so it stayed out of the
battery until that was fixed. Its bounds trained with Adam, whose steps do not shrink with c, and
its loss matched mean membrane potentials, which a clamped layer can match without spiking.

## Code review of 2026-10-22

- The Game reseeds before building the attack, because a learned trigger's initial weights came from
  an RNG state that depended on whether the clean model was cached.
- Executors write job folders under `<cache_dir>/jobs/`, never next to the tracked results, since
  `site.yaml` names the site's paths and accounts.
- Slurm array scripts `cd` into the job folder, so no path is quoted around the array index.
- `sbb reproduce --tolerance-pp 0` asks for an exact match, and `sbb validate` reports YAML syntax
  errors.
- The site sorts benchmark versions numerically, and a verification counts on the site only while
  the result still has the numbers it checked.
- Triggers refuse parameters they cannot apply. TMPBD refuses `steps: 0` and takes its input clamp
  from the card.
- ABL's unlearning runs through the Trainer with its weight decay in the card (bit-identical
  weights). STRIP moves its overlays to the device once.
- Deferred: reusing the cached victim as the reference model of spectral signatures and activation
  clustering, a lock per cache key against parallel cells building the same model, and a batched
  dynamic trigger on the GPU. Section 13.4 of the plan says how each ended.
